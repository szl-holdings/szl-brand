## Evidence language

| Label | Meaning |
| --- | --- |
| **REAL** | Directly backed by the named source within its stated scope |
| **MEASURED** | Direct observation with instrument, time, and context |
| **MODELED** | Simulation, projection, or analytical derivation |
| **ROADMAP** | Planned capability with no operational claim |
| **UNAVAILABLE** | Required evidence could not be inspected |

Operational state is separate. Use **OPERATIONAL**, **PARTIAL**, **DEGRADED**,
**UNAVAILABLE**, or **HISTORICAL** with a source and observation time.
